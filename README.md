"I built CareerHub, a full-stack AI career platform that turns a resume into real, actionable help. A user uploads their resume as a PDF; the backend extracts the text — with an OCR fallback for scanned files — and uses a Gemini LLM to parse it into structured data like skills, experience, and roles. From there it does three things. It scores the person against real job listings using local sentence-transformer embeddings and cosine similarity, so matching is free and keeps the resume private. It runs a conversational AI coach, NK, that's both resume-aware and job-aware — so when you click on a posting it can tell you why you're a 78% match and what one skill is holding you back. And it has a recruiter mode, where an HR user uploads a pool of resumes, ranks them semantically against a job description, and asks grounded questions about any candidate — every answer backed by an exact quote from the resume and a confidence flag, with a fairness guardrail that ignores name, gender, and age. Architecturally, the Python AI core sits behind a streaming FastAPI service with a React and Tailwind frontend — the shape real production AI apps use. I deliberately kept it cost-aware: it runs on a free Gemini tier with one LLM call on upload and lazy calls after, and all the semantic matching runs locally so there's no per-match cost
